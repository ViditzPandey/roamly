# 🌍 Roamly

A full-stack travel accommodation platform built with the **MEN Stack** where users can explore, create, edit, and manage listings, reviews, and user accounts.

## 🛠️ Tech Stack

* 🍃 MongoDB
* ⚡ Express.js
* 🟢 Node.js
* 🎨 EJS
* 🎨 Bootstrap 5

## ✨ Features

* 🏠 Create, view, edit & delete listings
* ⭐ Reviews & 1–5 star ratings
* 👤 User Signup & Login
* 🔐 Authentication & Authorization
* 🛡️ Passport.js authentication
* 🔒 Password hashing & salting
* 🍪 Sessions & Cookies
* 💬 Flash messages
* ✅ Joi validation
* ⚡ Centralized error handling
* 🧩 Modular Express Router
* 📱 Responsive UI

## 🔐 Authentication Flow

```text
Signup / Login
      ↓
Password Hashing
      ↓
Passport.js
      ↓
Session
      ↓
Authentication
      ↓
Authorization
      ↓
Protected Routes
```
